# 字节M3-Agent技术报告

## 1.核心概念

M3-Agent（Multimodal Memory Agent）是一个**具备长期记忆能力的多模态智能体框架**。该系统的核心设计理念是模仿人类认知机制——能够像人类一样处理实时视觉和听觉输入，构建并持续更新长期记忆。

## 2.创新点

| 特性 | 描述 |
| --- | --- |
| **多模态感知** | 同时处理视觉（视频）和听觉（音频）输入 |
| **双重记忆系统** | 情景记忆（Episodic Memory）+ 语义记忆（Semantic Memory） |
| **实体中心架构** | 以实体为核心的多模态记忆组织格式 |
| **自主推理能力** | 支持多轮迭代推理，从记忆中检索相关信息完成任务 |

## 3.记忆系统设计

M3-Agent系统分为三层，第一层环境输入层，可输入实时视频流+音频流+用户指令，第二层记忆构建层是由工具层（含有人脸检测和说话人分割）配合多模态大语言模型（MLLM）和实体中心、多模态格式组成的记忆存储组建的，之后进入第三层推理控制层，记忆检索相关片段后多轮推理迭代MLLM,输出需要的与环境交互的语音/文本回复。

### 3.1双重记忆架构

情景记忆：存储具体的时间和经历；保留时间、地点、人物等上下文信息；支持时间序列检索

语义记忆：积累世界知识和概念理解；从具体经验中提取抽象知识；支持跨场景的知识迁移

### 3.2实体中心的多模态记忆格式

记忆以**实体（Entity）**为核心进行组织，每个实体包含：**视觉特征**：人脸、物体外观、场景图像；**听觉特征**：声纹、语音内容；**关系图谱**：实体间的交互关系；**时间戳**：事件发生的时间线

## 4.**M3-Bench 评估基准**

### **4.1 数据集构成**

M3-Bench是专门为评估多模态智能体长期记忆推理能力而设计的长视频问答基准测试：

| **子集** | **视频数量** | **视频来源** | **特点** |
| --- | --- | --- | --- |
| **M3-Bench-robot** | 100 | 真实世界录制（机器人第一人称视角） | 真实交互场景 |
| **M3-Bench-web** | 920 | 网络采集 | 多样化内容和场景 |

### **4.2 评估能力维度**

基准测试涵盖以下关键能力：

1. **人物理解（Person/Human Understanding）：**识别视频中的人物；理解人物关系和情感状态；追踪人物行为模式
2. **通用知识提取（General Knowledge Extraction）**从视频中提取事实性信息；理解场景上下文；识别物体和位置关系
3. **跨模态推理（Cross-modal Reasoning）**结合视觉和听觉信息；音频-视频对齐理解；多源信息融合
4. **多证据推理（Multi-evidence Reasoning）**整合视频多个片段的信息；时间跨度推理；因果关系分析

### **4.3 典型问题示例**

**示例1 - 跨模态推理（M3-Bench-robot）**
