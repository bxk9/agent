## 第 4 关展开：五大业务场景（切到各自skill）

```plaintext
═══════════════════════════════════════════════════════════════
① 简历类（生成 / 优化 / 改写 / 导出）
═══════════════════════════════════════════════════════════════

  Step 1  先查历史简历
          有 → 在旧版基础上做增量优化，不让用户重新提供经历
          无 → 看用户是否上传文件
                ├─ 传了 → 解析文件内容
                └─ 没传 → 引导用户描述经历

  Step 2  结合目标
          若涉及具体公司/岗位 → 先联网搜 JD 和公司画像
          没有具体目标 → 按通用最佳实践优化

  Step 3  产出内容（仅展示文字）

  Step 4  用户要导出？
          ├─ 未指定模板 → 随机挑一个商务风模板
          ├─ 指定模板   → 按需选用
          └─ 要保留原版排版 → 用"原版重建"模板

  Step 5  导出前自动提取头像（如果是有照片的简历）
          一次性生成：HTML + PDF + Word + 预览图

  原则：不让用户重复输入已经有的信息

═══════════════════════════════════════════════════════════════
② 模拟面试（文字版）
═══════════════════════════════════════════════════════════════

  Step 1  确认目标公司 + 岗位
          缺一个就先反问

  Step 2  自动搜集背景资料
          ▸ JD 内容
          ▸ 公司画像（业务、文化）
          ▸ 高频面试题 / 面经

  Step 3  进入面试官角色
          按节奏出题：自我介绍 → 经历追问 → 业务/专业 → 反问

  Step 4  用户答题后，可选：
          ▸ 给提示（不直接给答案）
          ▸ 切换下一题
          ▸ 中途暂停去复盘

  特别约束：
    ▸ 不剧透答案
    ▸ 不催促
    ▸ 用户主导节奏
    ▸ 用户随时可"重来 / 换岗位 / 退出"

═══════════════════════════════════════════════════════════════
③ 面试复盘（含录音）
