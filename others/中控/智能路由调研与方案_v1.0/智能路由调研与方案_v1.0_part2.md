## 3.3. 开源框架：IRT-Router

本文提出的 IRT-Router 框架通过结合 IRT 理论和数据挖掘技术，提供了一种新的多 LLM
路由方法，显著提高了 LLM 路由的有效性和可解释性，并在实际应用中展示了其可靠性和
实用性。

## 1、算法流程

IRT 理论：一种心理测量理论，用于测量人类考生的能力，假设考生具有一定能力，题
目具有一定难度。通过建模考生输出正确答案的概率，得到人类考生能力与测试题目之间的
相关关系。
IRT 路由的框架原理如下：首先获取 query 和候选 LLM 的 embedding。然后利用基于 IRT
的模型预测每个 LLM 的性能。性能预测结果随后与 LLM 的固定成本结合，计算排名得分。
最后，query 会被路由到得分最高的 LLM。
主要流程 描述
Query 和 LLM 向量
化
使用预训练向量模型将 query 和 LLM 转换为向量。
IRT-based
Prediction
通过 MIRT 和 NIRT 两种实现方式预测 LLM 的性能。
MIRT：就是一个多项式逻辑回归，输入包括 query 特征、query 难度、
模型能力特征。
NIRT：除了上面三个特征外，引入了 25 种能力的相关向量特征（对应
维度的特征取 0/1），接线性层和 softmax 后输出。
路由决策
结合 LLM 性能预测结果和 LLM 固定成本进行加权后排名，选择最佳 LLM
作为输出。
冷启动机制
通过语义相似性对 query 进行预热，提高在线泛化能力。具体做法：
用当前 query 向量获取训练集中 k 最近邻向量，加权后得到调整后的
向量

## 2、架构特点

1）灵活性：支持多种配置参数，可以根据具体需求调整性能和成本的权衡。
2）数据集局限性：论文中使用的数据集主要是带标签的基准数据集，query 较短且多
样性不足，跟实际业务场景中的用户 query 差异较大。

## 3.4. 开源框架：RouteLLM

一个基于偏好数据的 LLM 路由原则框架，主要区分两种模型：一个更强且更昂贵的模型，
以及一个较弱但更便宜的模型。利用 Chatbot Arena 的公开数据训练了四个不同的路由器，
实验表明在不牺牲质量的情况下大幅降低成本，相比仅使用 GPT-4，MT Bench 的成本降低超
过 85%，MMLU 降低了 45%，GSM8K 降低了 35%，同时仍能实现 GPT-4 的 95%性能。

## 三、 核心创新：智能路由系统

## 论文提出了四种不同的路由器实现方式：

1. 相似度加权排序（SW Ranking）
- 基于 Bradley-Terry 模型得到实力值（即参数估计）
- 计算查询与训练数据的语义相似度
- 无需训练，推理时动态计算
2. 矩阵分解（Matrix Factorization）
- 借鉴推荐系统思想
- 学习查询和模型的隐含表示
- 通过双线性函数预测模型表现
- 核心原理：用低秩矩阵建模 “查询 - 模型适配性”
- 数学建模：从偏好标签到损失函数
3. BERT 分类器
- 使用 BERT-base 架构，将路由任务转化为 “二分类任务”，通过微调预训练 BERT 模型，
直接从查询的语义特征中学习 “强 / 弱模型适配性”。
- 全参数微调
4. 因果 LLM 分类器
- 基于 Llama 3-8B，将路由任务转化为 “指令式预测”，让模型直接理解查询意图并判断最
优模型。
- 采用指令跟随范式
