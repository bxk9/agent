## 智能路由调研与方案1. 背景与目标

## 1.1. 背景

大模型智能路由是根据任务特性和用户需求，利用多个模型的互补优势，将请求分配给
最适合的模型。在保证性能的同时优化成本与效率，避免“大炮打蚊子”式的资源浪费，和
“小马拉大车”式的能力不足。
目前各大厂商（如 openAI、微软、字节、腾讯）都构建了自己的路由服务。主要是通
过评估 query 复杂度、用户意图、成本和性能等因素，能高效地将 query 路由到最合适的模
型，确保高质量结果同时降低成本。

## 1、智能路由分类总结

智能路由通常有两大类：性能路由和任务路由。性能路由主要在于不同尺寸的模型中进
行选择，以平衡成本和延迟。而任务路由主要负责将 query 分配给特定领域的 Agent，以实
现更高的准确性。

## 2、业界常用的路由模型

业界采用的路由模型以小模型居多，如 bert 类模型，可能主要是出于效率性能和延时
的考虑。

## 3、业界常见的共性方法

很多方案都采用了向量召回方式快速获取路由结果，如 vLLM Semantic Router 的方案使
用语义缓存，直接返回缓存结果给用户。另外 IRT-Router 使用一种基于语义相似性的在线
query 预热技术，进一步增强方案的在线泛化能力。

## 3.2. 开源框架：vLLM Semantic Router

vLLM Semantic Router 是面向混合模型的智能路由框架，核心功能是通过语义理解将用
户 query 动态分派给最合适的模型，在保证关键任务准确性的同时大幅提升推理效率与延迟。
该框架解决了大模型推理中的核心矛盾：简单任务无需消耗昂贵算力，复杂任务需要深度推
理。它通过语义层面的智能判断，将简单 query 路由至"快速路径"（如基础模型），复杂或
高价值任务路由至"慢路径"（如带 Chain-of-Thought 的专业模型），实现效率与准确性的平
衡。
