# 整体框架

![整体架构.png](http://veditor.vivo.xyz/api/v1/attachment/file/wocibbtLGVjRE37ujM3fElDU0cecm--1alrHt4xv7jjsjlM1Ixw0xxyRwHCaE8eG "整体架构.png")

整体分为： 中控agent、子agent（自建agent、三方agent）两部分

【中控agent】：负责全局的规划编排，以react的形式判断“**需要调用哪个子agent执行哪个任务**”，拿到“**子agent结果后，再进行下一步任务的编排“**，直到“**任务结束，进行总结回复**”

备注：对于中控agent，一些常用工具，也可以在其能力支持的情况下，可以直接调用，比如联网搜索工具、闹钟工具（假设闹钟不作为独立agent存在的话）等

【子agent】：负责agent内部的规划编排，以react的形式判断“**需要调用哪个工具执行任务**”，拿到“**工具结果后，再进行下一步任务的编排**”，直到“**任务结束，将回复返回给中控agent**”

### 具体case时序图

![整体架构时序图.png](http://veditor.vivo.xyz/api/v1/attachment/file/DwdHid2d4e65LVxSWWDHU4yw6zSaapcSEBK5VXuR3tIA354gCQGhU7tjIeEp2CbB "整体架构时序图.png")

一个完整任务，拆分为不同的子任务，一个子任务的执行，都需要：选择工具 ——> 提取工具所需的参数 ——> 调用工具执行 ——> 获取工具结果； （其中如果工具是一个黑盒，则可以pass提取参数的步骤，直接执行工具获取结果），根据前一个子任务的结果，再决定下一个任务是什么

类比到做菜（西红柿炒蛋），拆分为：买菜，做菜两个子任务； 买菜又可以拆为：买西红柿和鸡蛋，付款 两个小任务；如果买菜阶段失败了，那么做菜就不需要了；

【总结】：中控agent 和 子agent， 在设计上其实是**可以完全相同的，只是其执行的任务侧重点**不同。

### 中控agent和子agent能力要求

【中控agent】：

1、能够**看到全局**可选的工具（or agent）

2、然后以react的形式选择工具（or agent）
