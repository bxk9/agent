5、【暂时不具备，但是优先级比较低】react的形式进行编排的能力（可以由pro中控agent承接）

#### Q：为什么flash中控模型升级为react形式的优先级较低？

A：

  1、【能够解决哪些问题】升级为react的形式，主要是为了解决：

    （1）：“多个工具，依赖前面工具的状态才能判断下一个工具选择哪个”这种意图类型无法拆解的问题——可以由pro模型来承接

    （2）：“在工具执行过程中，根据工具的实际执行状态判定当前任务是否已完成（举例：query=帮我查一下天气然后把天气信息用微信发给小明，如果中控能够知道天气已经查询失败了，则此时不再需要调用微信agent）”的问题——可以由pro模型承接

    （3）：复杂指令先思考再执行的能力：比如“帮我查一下喜马拉雅山那个县的天气”， 需要先思考喜马拉雅山所在的县在哪，然后调用天气api——可以由子agent做成react的形式来承接

    对于上面的问题，可以交由pro模型，或者具备react能力的子agent来实现，因此当前优先级不高；

  2、【升级的技术难度高么？】难度很高，react的形式进行PE（规划plan、执行execution），存在以下问题：

    （1）**开放动作搜索空间下，如何P，取决于E的执行能力（细粒度控制的能力）**： 举例“打开高德，导航到上梅林”，目前有两个工具A：打开应用；B：导航； 从路径上模型可以选择A+B， 而事实上只选择B，其实现的效果是相同的，甚至A+B反而可能出现问题；

    （2）**模型会倾向于使用已有工具**：即使在豆包1.6的理解能力下，该问题也明显存在：[http://docs.vivo.xyz/s/IlDVxIRf](http://docs.vivo.xyz/s/IlDVxIRf) 邀请您加入文档协作【问答闲聊接入3.0-前期度量摸底-定性】，将问答闲聊与工具同时给模型进行编排，准确率会降低； 需要更强的理解能力的模型或者定向微调（or强化学习）才可以
