### ④ 面试题库生成与模拟对话

| 维度 | 详细说明 |
| --- | --- |
| **输入** | 1. **目标 JD + 公司画像**（来自①）<br>2. **用户简历**（来自②，定制版优先）<br>3. **面经数据**：合作面经库 + 公开面经检索结果（按"公司+岗位+轮次"召回，附带发布时间用于时效加权）<br>4. **用户求职记忆**：过往错题、过往面试表现、个人薄弱标签、历史掌握度<br>5. **岗位级别**：社招（P5/P6/P7…）/ 校招（初级/管培）/ 实习等<br>6. **面试官类型**（可选）：HR / 直属上级 / 跨部门 / 高管 / 技术官<br>7. **用户偏好（可选）**：难度档（基础/中等/高强度/压力面）、风格偏好（结构化追问/发散思辨/案例分析/压力测试/闲聊式）、时长（10/20/30 分钟）<br>8. **模拟模式**：文字 /~~ 深度对话~~；练习模式（边答边反馈）/ 拟真模式（答完再反馈） |
| **处理逻辑** | **【准备阶段】**<br>1. **面经画像构建**（`interview.meta_profile`）：基于"公司+岗位+轮次"召回近 1-2 年面经，自动提炼：<br>- **难度档位**（基础/中等/高强度/压力面，按追问深度+八股密度+案例复杂度判定）　<br>- **风格特征**（结构化追问 / 发散思辨 / 案例分析 / 压力测试 / 闲聊式）　<br>- **时长惯例**（30/45/60 分钟）　<br>- **高频考点 Top5**（按面经命中频次）　<br>- **面试官追问模式**（追问层数、是否爱挑数据口径、是否爱问反例）　<br>- **数据透明**：每项判断标注"基于 N 条面经 / 最近 90 天 N 条"，<5 条时标注"参考度有限"<br>2. **轮次与偏好确认**（`interview.session_setup`）：　<br>- **必询问**：第几轮（一面/二面/HR/终面/技术面），用户未说时主动询问　<br>- **主动告知**：基于面经画像告诉用户"本场预计偏 XX 风格、YY 难度、Z 分钟"　<br>- **询问偏好**：是否需要调整难度/风格/时长？无需求 → 直接按面经画像开始；有需求 → 按用户指定调整<br>3. **历史表现联动**：调取 ⑥ 求职记忆中该公司岗位的历史模拟/真实面试，对已掌握考点降权、薄弱考点升权（用户主动选"重新练一遍"则跳过此联动）<br>4. **岗位级别加权**：根据社招/校招级别调整题目深度（如 P7 加权"系统设计/跨团队协调"、校招加权"基础八股 + 项目细节"）<br>**【生成阶段】**<br>5. **题库生成**（`interview.question_bank_gen`）：按"行业基础题 + 岗位专业题 + 公司特异题 + 简历追问题 + 行为面试题"五类组卷，依据面经画像 + 偏好分配各类占比；每题标注难度/考点/出题依据（来自哪条面经/JD 第几条/简历哪段经历）<br>6. **会话上下文构建**（`interview.session_context`）：把简历+JD+公司画像+面经画像注入对话上下文，让模拟面试官"读过你的简历"且"是这家公司风格"<br>**【对话阶段】**<br>7. **开场白告知**：将【**面经画像构建**】整体总结后输出给用户，但不要太长，用 2-3 句话告知用户"本次模拟将参考 XX 公司 YY 岗位 N 条面经（最近 90 天），整体风格偏 ZZ，难度 W 档，预计 M 分钟 K 题"<br>8. **多轮模拟对话**：按面经画像沿用的节奏与风格出题→倾听回答→自然追问→切题；追问层数、追问偏好与该公司风格对齐<br>9. **过程中动态调档**（`interview.dynamic_adjust`）：用户中途说"太难了 / 太简单了 / 换种风格 / 多问点项目细节" → 实时调整后续题目难度/风格/侧重<br>10. **时长节奏控制**：按用户选择时长自动控制题目数量与深度，到时自然收尾，不无止境出题<br>11. **对齐式反馈**（`answer.alignment_check`）：每个回答给出"覆盖到 JD/画像的哪些点 / 漏了哪些点 / 表达可以怎么调"，**不打分**<br>12. **双反馈模式**：练习模式（边答边反馈）/ 拟真模式（答完整轮再统一反馈）<br>**【兜底】**<br>13. **面经不足降级**：召回面经 <5 条时，主动告知用户"该岗位面经较少，将基于通用模板生成"，并请用户手动指定难度/风格 |
| **输出** | - **面经画像**（难度/风格/时长/Top5 考点/追问模式 + 数据来源透明度）<br>- **本次模拟参数确认**（轮次/难度/风格/时长，明确告知用户）<br>- **个性化题库**（结构化题目列表，含考点/难度/依据/参考面经 ID）<br>- **模拟会话记录**（多轮 Q&A，含追问层级与动态调档记录）<br>- **每题对齐反馈**（覆盖项/漏项/表达建议/参考思路）<br>- **整轮总结**（强项标签/薄弱标签/建议补强方向 + 与历史表现对比）<br>- **错题沉淀**（薄弱题自动进入错题本，流入能力⑥） |
