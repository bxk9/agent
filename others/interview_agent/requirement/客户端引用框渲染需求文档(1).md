# 客户端需求文档：Agent 回答末尾新增引用框（Reference Block）渲染

## 1. 背景

当前 Agent 在回答用户问题时，会调用搜索类工具（`web_search` / `smart_search` / `web_search_on_sites` 等）获取最新信息。这些信息源对回答质量很关键，希望在回答下方以"引用框 / Sources / 参考资料"形式展示信息源，点击可跳转。我们希望端侧也支持这套交互。

---

## 2. 目标

- **服务端**：在 Agent 回答的最终 artifact 中，metadata 里**新增一个references字段**
- **客户端**：识别该字段，在答案下方渲染**引用框 **  

---

## 3. 协议改动

接口定义参考：`claw云网关协议V2.md` §4.2 Artifact / §5.5 task/artifactUpdate

### 3.1 字段位置

利用 A2A 协议 `Artifact` 对象的 `metadata` 字段（协议 4.2 节，open 字段）。

```json
{
  "artifactId": "artifact-stream-xxx",
  "name": "answer",
  "parts": [...],
  "metadata": {
    "references": [ /* 见 3.2 */ ]
  }
}
```

### 3.2 字段结构

`metadata.references`：`Reference[]`（数组，可能为空但建议存在即非空）。

```typescript
interface Reference {
  // 必填
  index: number;       // 引用序号（从 1 开始），用于答案中 [1][2] 角标对应
  title: string;       // 标题（≤ 80 字符，超长前端可截断 + 悬停 tooltip）
  url: string;         // 跳转链接（http/https 公网可达）

  // 可选
  snippet?: string;    // 摘要片段（≤ 200 字符）
  source?: string;     // 来源域名 / 平台名（如 "知乎"、"GitHub"、"vivo 招聘官网"）
  publishTime?: string; // ISO 8601 发布时间（如 "2026-05-12T08:30:00Z"）
}
```

### 3.3 完整示例

```json
{
  "jsonrpc": "2.0",
  "method": "task/artifactUpdate",
  "params": {
    "taskId": "task-xxx",
    "contextId": "ctx-xxx",
    "artifact": {
      "artifactId": "artifact-stream-xxx",
      "name": "answer",
      "parts": [
        {
          "text": "vivo 校招 AI 产品经理面试通常分 3 轮 [1]：技术初面、业务面、HR 面 [2]……",
          "mimeType": "text/markdown"
        }
      ],
      "metadata": {
        "final": true,
        "references": [
          {
            "index": 1,
            "title": "vivo 2026 校招 AI 产品经理面经",
            "url": "https://www.nowcoder.com/discuss/xxxxx",
            "snippet": "一面：项目深挖 + 系统设计；二面：业务理解 + 案例分析……",
            "source": "牛客网",
            "publishTime": "2026-04-15T00:00:00Z"
          },
          {
            "index": 2,
            "title": "vivo 招聘 - AI 产品经理 JD",
            "url": "https://hr.vivo.com.cn/jobs/xxxxx",
            "source": "vivo 招聘官网"
          }
        ]
      }
    },
    "append": false,
    "lastChunk": true
  }
}
```

## 4. 客户端渲染要求

```
┌─ 📚 参考资料（共 2 条）────────────┐
│ ┌─────────────────────────────┐   │
│ │ [1] vivo 2026 校招 AI 产品…  │   │
│ │      牛客网 · 2026-04-15    │   │
│ │      一面：项目深挖+系统…    │   │
│ └─────────────────────────────┘   │
│ ┌─────────────────────────────┐   │
│ │ [2] vivo 招聘 - AI 产品经…   │   │
│ │      vivo 招聘官网          │   │
│ └─────────────────────────────┘   │
└────────────────────────────────────┘

┌─ Agent 回答正文 ─────────────────────┐
│ ……答案内容…… [1][2]……              │
│ ……更多内容……                        │
└────────────────────────────────────┘
```

**交互行为**：

- 点击链接 → 支持浏览器打开 `url`

  

---

## 5. 服务端改动（agent 侧自行落地，仅供客户端理解）

服务端在生成最终 artifact 时,  收集本轮所有搜索类工具调用的返回结果，提取 (title, url, snippet, source) 字段, 返回`metadata.references`字段
