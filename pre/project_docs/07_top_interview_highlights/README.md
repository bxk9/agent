# 07 · 面试算法工程师 · TOP 12 最有价值工作精选

> **章节定位**：从项目 7 位主要贡献者的全部工作中，**以"面试算法工程师"视角**精选 12 项最能体现算法/AI 工程能力的关键工作，逐项深度拆解——从**问题定义、方案选型、算法/工程实现、量化验证、迁移与复用**五个维度呈现，作为技术面试或作品集展示的核心材料。
>
> **选材原则（面试算法工程师视角）**：
> 1. **有算法或 AI 工程深度**（非纯业务 CRUD）
> 2. **有清晰的问题定义与量化验证**
> 3. **有方法论抽象**（能讲出可复用的原则/模式）
> 4. **有端到端闭环**（从问题发现到方案落地）
> 5. **有真实业务场景背书**（不是玩具项目）

## 每篇文档的深度结构

为面试展示优化，每篇文档采用**七段式深度结构**：

1. **一句话摘要**（30 秒电梯演讲）
2. **面试价值卡片**（能讲什么、能答哪些经典面试题）
3. **背景与问题定义**（业务上下文 + 为什么难 + 量化痛点）
4. **方案演进与关键决策**（不只是"怎么做"，还有"为什么这么做"、"淘汰了什么方案"）
5. **算法/工程实现细节**（伪代码、关键 diff、边界处理）
6. **量化验证与效果**（前后对比、A/B、指标）
7. **方法论抽象与迁移**（能否推广到其他场景、失败模式警示）
