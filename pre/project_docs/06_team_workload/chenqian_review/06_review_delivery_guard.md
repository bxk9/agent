## 拦截项清单

### 1. 场景硬闸（07-22）

**问题**：转写后模型跳过复盘 skill 直接输出
**拦截**：业务动作前置检查——是否为复盘场景 → 必须走 skill

**收窄**：仅约束复盘，不干扰简历/mock 面试

### 2. 逐题全覆盖 + 题数自检（07-23）

**Skill 层**：硬约束"必须覆盖所有题目"
**交付前**：自检声明题数 vs 实际逐题分析块数
**08-07 工具层**：不一致 → 拒绝入库 + 记录漏题原因

### 3. 材料兜底（07-23）

**场景 A**：非语音 mock 面试想复盘，但没材料
- 兜底查最近一场错题
- 展示题目供用户确认

**场景 B**：兜底展示题目时
- 一并列出用户回答
- 供用户确认再进入复盘

### 4. 事实围栏（07-01, 07-23）

- 重答参考事实围栏（07-01）
- 复盘不提转写误差/统一术语建议（07-23）
- 专名同音变体按误识还原（07-23）
- 原话保原样、分析用标准术语

### 5. 数字铁律（07-22 五连修）

- 禁虚构数字
- 禁占位与编造混用
- 禁档位词（"优秀"、"良好"等空话）
- 背景/情景数字必占位

---

## 方法论：三层缺一不可

| 层 | 缺失时的问题 |
|:---|:---|
| **Skill 软约束** | 缺失 → 模型无引导，输出发散 |
| **交付前自检** | 缺失 → 明显问题溜过去 |
| **工具入库拦截** | 缺失 → 脏数据污染索引层 |

陈乾用三层防御让复盘输出**从"看运气"变成"看架构"**。
