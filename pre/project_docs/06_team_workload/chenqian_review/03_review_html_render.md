## 方案演进

### 阶段一：文本 → HTML（07-09）

**痛点**：文本报告在手机端展示混乱，无法保留结构
**方案**：
- Skill 直接输出 HTML（而非 Markdown）
- HTML 上传 VFS，仅返回链接
- 文件名规范为 ASCII（避免中文 URL 编码问题）

**收益**：
- 报告可分享（链接）
- 结构完整（表格、列表、卡片）
- 减少对话流中的长文本刷屏

### 阶段二：移动端适配（07-15）

**痛点**：宽表格在手机端撑破卡片、横向滚动体验差
**方案**：
- `max-width: 100%`
- `overflow-x: auto` 局部
- 关键表格改为纵向列表

### 阶段三：视觉治理（07-20）

**两个修复**：
1. 有序列表序号 `1. 2. 3.` 在窄容器下溢出白色卡片 → CSS 调整 `list-style-position: inside`
2. 视觉分区引导 → 加分区标题 + 分色卡片

- 复盘 Skill 在 stream 完成前先返回 HTML 链接
- 协议层把链接注入到最后一个 chunk 的 parts
