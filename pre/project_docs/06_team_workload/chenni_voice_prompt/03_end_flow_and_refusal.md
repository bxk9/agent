## 三段话术设计

### 段 1：开场白（08-05 约束）

**约束**：开场白不计入题目数量
**内容**：
- 面试官自我介绍
- 说明本轮面试性质
- 邀请用户自我介绍

### 段 2：拒答引导（08-03）

**问题场景**：
- HR 面：用户被问到"你为什么离开上家"，可能不愿意答
- 行为面：用户被问到"你处理过最难的冲突"，可能没经历

**旧行为**：AI 硬追问 → 用户尴尬

**新话术**：
```
面试类型: HR/行为面
用户拒答 →
  AI: "没关系，这个问题可以暂时跳过。我们换一个角度……"
```

**关键**：不是无脑跳过，而是**换角度重问**，让用户能有话可答。

### 段 3：结束反馈（07-30）

**旧结束**：`"面试结束，谢谢。"`

**新结束**：
```
1. 整体表现反馈（简短、鼓励为主）
2. 亮点点名（1-2 个）
3. 改进建议（1-2 个）
4. 引导到复盘工具（"想看详细复盘吗？"）
```

**引导价值**：把用户导流到陈乾负责的**复盘链路**，形成业务闭环。

---

## 类型分流

不同面试类型的结束反馈重点不同：

| 类型 | 反馈重点 |
|:---|:---|
| 技术面 | 技术深度、思路清晰度 |
| HR 面 | 沟通表达、动机契合 |
| 行为面 | STAR 完整性、真实性 |

---

## 与业务闭环

```
陈妮：语音面试对话
  ↓ 结束引导
陈乾：复盘链路（HTML 报告）
  ↓ 错题入库
yitong：错题本
  ↓ 下次面试
陈妮：出题方向结合错题
```

四个模块形成完整闭环。
