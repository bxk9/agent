# 02 · 出题方向与策略

## 一句话概括

陈妮在 07-30 完成的**"具体题目 → 出题方向"抽象升级**，是语音面试提示词工程的关键转折——从"AI 给你 10 道预设题"变成"AI 像真人面试官一样按方向自由发挥"。

---

## 关键转折：具体题目 → 出题方向（07-30）

### 旧模式（具体题目）

```
Skill 里预设：
Q1: 谈谈 React 生命周期
Q2: 什么是闭包
Q3: 说下你最有挑战的项目
...
```

**问题**：
- 千人一面
- 与用户简历脱节
- 用户回答完 Q1，AI 无脑跳到 Q2（不追问）

### 新模式（出题方向）

```
Skill 里给方向：
方向1: 前端框架深度（React/Vue 生命周期、状态管理）
方向2: JS 基础（闭包、原型链、异步）
方向3: 项目深挖（用户简历中最新项目 → STAR）
```

**AI 行为**：
- 根据用户简历选方向
- 根据用户回答动态生成具体题目
- 支持追问和延伸
- 感觉像真人面试

## 简历结合（07-31）

**问题**：出题方向虽好，但初期不结合简历 → 泛泛而问

**修复**：
- Skill 显式要求"读取用户简历"
- 优先出用户简历中提到的技术栈
- 未提到的技术栈作为"扩展检验"（少量）

**协作**：与 11099826 的 resume_parser、yitong 的错题本形成三方联动。

---

## 难度自适应（07-31）

**行为面难度自适应**：
- 初级用户：只问基础行为（团队协作、时间管理）
- 高级用户：进阶行为（冲突处理、跨部门推动、失败复盘）

**技术面难度自适应**：
- 简历中出现"专家/高级"等词 → 拉高难度
- 简历中项目复杂度低 → 出基础题

---

## 出题顺序（08-03）

**默认顺序**：
1. 自我介绍
2. 项目深挖（用户熟悉的先问，建立信心）
3. 技术基础
4. 行为面
5. 反问环节
6. 结束

**修改原因**：
- 之前把技术题放最前 → 用户容易紧张
- 现在从熟悉的项目开始 → 更接近真实面试
