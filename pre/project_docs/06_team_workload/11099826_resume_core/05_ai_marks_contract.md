## 背景与问题

LLM 会做两类"补写"：
1. **补数字**：如"提升 30%"这类量化指标是 LLM 编的
2. **补内容**：如"熟练掌握 XX 技术"这类主观描述

如果不标记，用户以为都是自己写的，会有**真实性风险**。

## 方案 / 代码证据

### 契约层级

```
1. Prompt 层：明确要求 LLM 用 <<<[X]>>> 或类似标记包裹补写内容
2. 归一化层：normalize.py 保留标记不清洗
3. 校验层：validate.py + fact_store.py 校验真实性
4. 标记层：ai_marks.py 生成 diff / 定位
5. 渲染层：pipeline.py 在最终产物中把标记转换为紫色 span
6. 交互层：前端识别标签，用户可 hover 看到"AI 补写"提示
```

### 颜色系升级动机

- **红色（初版）**：太警示，让用户觉得"错了"
- **紫色 #8b5cf6（08-08）**：AI 感更中性，符合 AIGC 标识国际惯例
