# 01 · 简历解析入口（resume_parser.py）

## 一句话概括

`resume_parser.py` 是简历生成链路的**上游入口**——把用户上传的 doc/docx/pdf 文件转成结构化 JSON，喂给下游侧边栏 pipeline。11099826 是该文件的**首要 Owner（blame 占 63.8%）**，与 11197109（31.3% / VLM 侧）形成"文本解析 + 视觉解析"双主控。

## 背景与问题

- 项目初始阶段（06-05）需要支持任意格式简历上传并落地为可编辑 JSON
- 后期演进出多个新问题：
  - VLM 视觉模型接入（11197109 主导）需要与原有文本解析并存
  - 校园活动 vs 学习部长身份等**语义边界**难以判断
  - 时间字段格式（"2020.9-至今"）、专利号丢失、荣誉表格逐字拆分等**长尾问题**
  - 字段自创（LLM 幻觉生成英文键名）导致下游渲染异常

## 方案 / 代码证据

### 三层结构

1. **上传接入层**：与 `resume_export.py`、VFS 客户端协作，接收 URL / 二进制流
2. **解析路由层**：文本 / 视觉 / 兜底三分支
3. **字段落地层**：与 `resume_sidebar/normalize.py` 契约对齐

### 关键设计

- **白名单豁免机制**（08-04）：校园办公室不再被误判为工作经历
- **英文键名兜底**（08-07）：LLM 自创 `self_assessment` 时不再让下游模块崩溃
- **VFS URL 三层兜底读取**（08-07）：与 rebuilt 质量评分联动
