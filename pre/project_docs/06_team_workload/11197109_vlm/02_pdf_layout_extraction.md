## 版式还原问题域

### 1. 图标与横线（07-16）

**问题**：PDF 中的分割线、图标（例如 📧 电话/邮箱图标）在还原时丢失或错位
**修复**：HTML 端识别并保留装饰元素

### 2. HTML 适配 PDF（07-17）

**问题**：HTML 排版直接转 PDF 会破版
**修复**：为 PDF 专门约束 CSS（页边距、字号、可打印性）

### 3. 表格逐字拆分（07-31）

**问题**：荣誉证书表格被逐字拆分成单元格
**根因**：VLM 对稀疏表格的识别倾向"每字一格"
**修复**：合并规则 + 结构后处理

### 4. 字段完整性三连修（08-03）

一天内修复了简历核心字段的三个大问题：

| 问题 | 表现 | 影响域 |
|:---|:---|:---|
| **主修课程列表字面量** | 渲染出 `['A', 'B', 'C']` 字符串 | 教育背景 |
| **项目经验只剩标题** | 项目细节全部丢失 | 项目经验 |
| **时间全部丢失** | 工作/教育/项目起止时间 | 三类字段 |

**深度**：一天三连修显示问题定位链条清晰、修复能力强。

### 5. PDF 分页问题（08-07）

**问题**：多页简历分页时内容错位、留白不均
**修复**：CSS `page-break-*` 精细化控制
