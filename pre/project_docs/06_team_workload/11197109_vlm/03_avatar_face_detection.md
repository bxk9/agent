## 双路方案

### Path A：VLM 提取（首选）

**输入**：PDF 页面截图
**输出**：头像区域坐标 + crop 后的图像
**优点**：能识别复杂背景中的人像
**缺点**：偶发失败（网络、内容审核）

### Path B：OpenCV 人脸检测（兜底）

**输入**：同上
**方案**：Haar Cascade / DNN face detector
**优点**：零延迟、稳定、离线
**缺点**：对遮挡、侧脸鲁棒性差

### 融合策略

```
1. 优先 VLM 提取
2. VLM 失败 / 返回可疑区域 → OpenCV 兜底
3. 都失败 → 无头像（不阻塞流程）
```

---

## 关键修复

### 08-03 头像提取修复

- 修正 crop 边界（头像被切边）
- 增加安全边距（避免 tight crop 只留脸不留头发/肩膀）

### 08-04 OpenCV 引入

**动机**：VLM 兜底路径质量低，需要更稳定的技术方案
**成本**：新增依赖 opencv-python
**收益**：头像提取成功率显著提升

### 08-06 PDF 头像提取

**问题**：早期只处理图像输入，PDF 内嵌头像被忽略
**修复**：PDF → 页面渲染 → 头像检测 → crop
