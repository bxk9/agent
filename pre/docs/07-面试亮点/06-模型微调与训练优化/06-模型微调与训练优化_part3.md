## 8. 面试问答准备

### Q1: 为什么选择LoRA而不是全量微调？

**A**: 
1. **成本考虑**：全量微调需要8×A100，成本$2400；LoRA只需要2×A100，成本$300，降低87.5%
2. **效果接近**：LoRA准确率96%，全量微调97%，只差1%，但成本差8倍
3. **灵活性**：LoRA可以为不同任务训练不同的适配器，切换方便
4. **训练速度**：LoRA训练6小时，全量微调12小时，快2倍

### Q2: 如何确定LoRA的超参数（rank、alpha、学习率）？

**A**:
1. **Rank**：通过消融实验，测试16/32/64/128，发现64是最佳选择（效果和效率平衡）
2. **Alpha**：通常设置为rank的2倍（128），这是一个经验值
3. **学习率**：通过消融实验，测试1e-4/2e-4/5e-4/1e-3，发现2e-4是最佳选择（准确率高且稳定）
4. **参考论文**：参考LoRA原论文和Qwen官方推荐的超参数

### Q3: 如何保证训练数据的质量？

**A**:
1. **数据来源**：从生产环境日志中提取真实数据，确保数据分布与实际场景一致
2. **数据清洗**：过滤掉过短、标签不完整、标签错误的样本
3. **数据平衡**：过采样少数类，欠采样多数类，避免模型偏向多数类
4. **人工审核**：对高频query进行人工审核，确保标签准确
5. **数据增强**：通过同义词替换、句式变换等方式增强数据多样性

### Q4: 微调后Prompt为什么可以简化？

**A**:
1. **基座模型需要详细Prompt**：基座模型没有见过路由分类任务，需要详细的分类标准和示例来引导
2. **微调后模型已学习任务**：微调后模型已经学习了路由分类的模式，不需要详细的分类标准
3. **Prompt简化**：从3000 tokens（详细分类标准+14个示例）简化到1500 tokens（简化指令+工具定义+用户输入）
4. **效果反而更好**：简化后的Prompt更聚焦，模型更容易理解，准确率反而提升

### Q5: 如何评估微调的效果？

**A**:
1. **准确率**：在测试集上评估准确率，从85%提升到96%
2. **各维度准确率**：分别评估4个维度的准确率，确保每个维度都有提升
3. **推理性能**：对比推理延迟、吞吐量、Prompt长度
4. **A/B测试**：在生产环境进行A/B测试，验证实际效果
5. **消融实验**：通过消融实验验证每个超参数的影响

### Q6: 这个方案有什么局限性？

**A**:
1. **数据依赖**：需要大量高质量的标注数据（50,000条）
2. **训练成本**：虽然比全量微调低，但仍需要2×A100，成本$300
3. **领域特定**：微调后的模型只适用于路由分类任务，泛化能力下降
4. **更新成本**：如果分类标准变化，需要重新训练模型
5. **MoE支持**：不是所有训练框架都支持MoE模型的微调

### Q7: 如何进一步优化？

**A**:
1. **数据增强**：使用更多数据增强方法（如回译、对抗训练）
2. **多任务学习**：同时学习多个相关任务，提升泛化能力
3. **持续学习**：定期用新数据微调模型，适应数据分布变化
4. **模型蒸馏**：将大模型蒸馏到小模型，进一步降低推理成本
5. **RLHF**：使用人类反馈强化学习，进一步提升准确率
