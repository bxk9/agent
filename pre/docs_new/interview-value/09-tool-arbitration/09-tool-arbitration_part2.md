1. 在 configs/ 下创建 JSON 元数据文件
2. 在同目录下创建 MD 策略正文文件

重启服务或调用 reload_rules() 即可生效。

**Q: 仲裁系统与 Patch 系统的区别是什么？**

A: 
- **仲裁系统**：解决工具共现冲突，注入长策略正文（MD 文件）
- **Patch 系统**：动态干预，注入短提示词（200 字限制）

分工明确：长策略投仲裁，短提示投 Patch。

**Q: 如何评估仲裁规则的效果？**

A: 通过以下指标：
1. **命中率**：规则被触发的次数
2. **准确率**：命中后模型选择正确工具的比例
3. **用户反馈**：用户是否投诉工具选择错误

可以通过日志聚合系统分析这些指标。
